Small scripts built while learning Python fundamentals.

| Script | What It Does |

| grocery-bill-calculator.py | Calculates grocery bill with 10% discount if total exceeds ₹1000 |

- User input

- Arithmetic operations
- If/else conditions

| atm-pin-validator.py | Simulates ATM PIN entry with 3 attempts before card block |
- While loops
- Break statement
